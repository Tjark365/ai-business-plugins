# B2B Sales Agent

Build qualification, objection handling and measurable B2B sales playbooks.

## Free
- Preview only
- Maximum 3 results
- No fabricated facts, contacts, pricing or intent

## Pro
Full workflow when the host supplies Pro entitlement.

## Local run
`python app.py`

## Environment
Optional `SERPER_API_KEY` or `BRAVE_API_KEY` for live public web research.

This project is source code hosted in GitHub; GitHub Actions can run its tests automatically.
